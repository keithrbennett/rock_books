# Test Coverage Report

Using the cov-loupe MCP server, examine the test coverage for this project and write a detailed markdown-formatted report about it.

The data is not as important as your analysis of that data. Which parts of the code base lack coverage? How critical is it for those parts? How difficult would it be to resolve?

Create a prioritized list including severity and time to fix.

Save the report to a markdown file whose file name is like:

`test-coverage-report-2026-01-27-1324-claude.md`

where the date/time is the current time in UTC and you include your model name ("claude", "codex", "gemini", "z-ai", etc.)
